# Radinho 
Projeto de clone do spotify 

um clone funcional do Spotify, projetado para rodar de forma local no computador. O aplicativo permite ao usuário selecionar uma pasta específica do seu próprio PC para servir como biblioteca musical, extraindo e organizando automaticamente os arquivos de áudio, nomes das faixas e imagens de capa para exibição na interface.

Funcionalidades:

  * Arquivos Locais: Importação automática de músicas e capas a partir de uma pasta escolhida pelo usuário.

  * Sistema de Playlists: Criação, organização e gerenciamento de listas de playlist personalizadas.
  
  * Modo Aleatório: Reprodução de faixas em ordem aleatoria.
  
  * Mecanismo de Pesquisa: Campo de busca rápida para localizar músicas por nome ou artista.

  * Controle de midia: botões para reproduzir, retroceder e avançar faixa, além de uma barra de reprodução para escolher momentos especificos da musica.
